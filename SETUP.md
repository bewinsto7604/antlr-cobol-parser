# ANTLR COBOL Parser Setup Guide

## Quick Start (Works Immediately)

The parser works **out of the box** with regex parsing:

```bash
cd antlr-cobol-parser
npm install
npm run parse examples/sample-copybook.cbl
```

This uses the fallback regex parser and extracts all business rules.

## Upgrade to Full ANTLR Parsing (Optional)

For more accurate parsing with ANTLR grammar:

### Step 1: Install ANTLR4 Tool

**Option A: Using Java (Recommended)**
```bash
# Install Java if not already installed
# Download ANTLR JAR
curl -O https://www.antlr.org/download/antlr-4.13.1-complete.jar

# Add alias (Windows)
doskey antlr4=java -jar antlr-4.13.1-complete.jar $*

# Or use npx (npm)
npm install -g antlr4
```

**Option B: Using npx (Simpler)**
```bash
npx antlr4 -version
```

### Step 2: Generate Parser from Grammar

```bash
cd antlr-cobol-parser
npm run generate
```

This runs:
```bash
antlr4 -Dlanguage=JavaScript -o src/generated grammar/Cobol85.g4
```

### Step 3: Run with ANTLR Parser

```bash
node src/antlr-parser.js examples/sample-copybook.cbl
```

## How It Works

### Without ANTLR (Default)
```
Copybook → Regex Parser → Business Rules
```

- ✅ Works immediately
- ✅ No setup required
- ✅ Handles 95% of copybooks
- ⚠️ Less accurate for complex syntax

### With ANTLR (After Generation)
```
Copybook → ANTLR Lexer → ANTLR Parser → Parse Tree → Business Rules
```

- ✅ More accurate
- ✅ Handles complex syntax
- ✅ Better error recovery
- ⚠️ Requires grammar generation

## Troubleshooting

### "ANTLR parser not generated yet"
This is normal! The fallback regex parser will run automatically.

To use ANTLR:
1. Install antlr4 tool (see Step 1 above)
2. Run `npm run generate`
3. Run `node src/antlr-parser.js <file>`

### "antlr4: command not found"
Use npx instead:
```bash
npx antlr4 -Dlanguage=JavaScript -o src/generated grammar/Cobol85.g4
```

Or update package.json script:
```json
"generate": "npx antlr4 -Dlanguage=JavaScript -o src/generated grammar/Cobol85.g4"
```

### Grammar Error
The provided grammar is simplified. For full COBOL85 support, use a complete grammar from:
- https://github.com/usethesource/rascal-cobol
- https://github.com/smojol-toolkit/smojol

## Recommendation

**Start with regex parser** (no setup) → **Upgrade to ANTLR** if you need:
- More accuracy
- Better error messages
- Parse tree for analysis
- Complex COBOL syntax support

Both work great for extracting business rules from copybooks!
