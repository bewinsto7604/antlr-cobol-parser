# Business Rules Extraction Workflow

This document explains the workflow for extracting and consolidating business rules from NJ2BE067.cbl and COSMATRX.

## Overview

The workflow consists of 3 steps:

1. **Extract NJ2BE067 rules** → produces `NJ2BE067-rules-extracted.md`
2. **Generate merge prompt** → produces `MERGE-PROMPT.txt`
3. **Run prompt with LLM** → produces final consolidated business rules

## Files

### Input Files
- `cobol/NJ2BE067.cbl` - COBOL program that determines COS codes
- `copybook/COSMATRX-integrated-report.md` - Base COSMATRX rules (109 rules)
- `copybook/ZCLMACTU.cpy` - Copybook with data element definitions

### Scripts
- `extract_nj2be067_rules.py` - Extracts override, COSMATRX traversal, and fallback logic from NJ2BE067.cbl
- `generate_merge_prompt.py` - Generates a prompt to merge NJ2BE067 + COSMATRX rules

### Output Files
- `cobol/NJ2BE067-rules-extracted.md` - Extracted rules from NJ2BE067.cbl
- `cobol/MERGE-PROMPT.txt` - Prompt for LLM to generate consolidated report
- `cobol/NJ2BE067-CONSOLIDATED-RULES.md` - Final consolidated business rules (generated by LLM)

## Step-by-Step Instructions

### Step 1: Extract NJ2BE067 Rules

Run the extraction script:

```bash
python extract_nj2be067_rules.py
```

This produces `cobol/NJ2BE067-rules-extracted.md` containing:
- 3 override rules (lines 77-90)
- COSMATRX traversal logic (lines 95-115)
- 2 fallback rules (lines 109-113)
- Medicare crossover handling logic (lines 240-252)

### Step 2: Generate Merge Prompt

Run the prompt generation script:

```bash
python generate_merge_prompt.py
```

This produces `cobol/MERGE-PROMPT.txt` - a comprehensive prompt that:
- Includes NJ2BE067 rules extraction
- Includes COSMATRX base rules (109 rules)
- Provides detailed instructions for merging
- Specifies output format requirements

### Step 3: Run Prompt with LLM

1. Open `cobol/MERGE-PROMPT.txt`
2. Copy the entire contents
3. Paste into your LLM (Claude Sonnet, GPT-4, etc.)
4. The LLM will generate the consolidated business rules report
5. Save the output as `cobol/NJ2BE067-CONSOLIDATED-RULES.md`

## What the Consolidated Report Contains

The final consolidated report will include:

### Summary
- Total Override Rules: 3
- Total COSMATRX Rules Called: 109
- Total Fallback Rules: 2
- Total Rules: 114

### Rule Categories

1. **Override Rules (001-003)**
   - COS 94: GSHP (Garden State Health Plan)
   - COS 37: Managed Care
   - COS 60: Laboratory (lab format procedures)
   - These execute BEFORE COSMATRX traversal

2. **COSMATRX Rules (004-112)**
   - All 109 COSMATRX base rules called via matrix traversal
   - Some rules have conditional exclusions added by NJ2BE067
   - Medicare Part A/B crossover variations documented
   - Multi-rule COS codes documented individually (e.g., 23A has 17 rules)

3. **Fallback Rules (113-114)**
   - COS 08C: Other Clinic (for Claim Type 18)
   - COS 99: Other (default for unmatched claims)
   - These execute when COSMATRX returns no match

## Processing Flow

```
Claim Data Input
       ↓
┌──────────────────────────────────────┐
│  1. Override Rules (Lines 77-90)     │
│     - GSHP? → COS 94, EXIT           │
│     - Managed Care? → COS 37, EXIT   │
│     - Lab format? → COS 60, EXIT     │
└──────────────────────────────────────┘
       ↓ (if no match)
┌──────────────────────────────────────┐
│  2. COSMATRX Traversal (Lines 95-115)│
│     - Evaluate 109 matrix rules      │
│     - Apply conditional exclusions   │
│     - Handle Medicare crossovers     │
│     - Return matched COS or no match │
└──────────────────────────────────────┘
       ↓ (if no match)
┌──────────────────────────────────────┐
│  3. Fallback Rules (Lines 109-113)   │
│     - Claim Type 18? → COS 08C       │
│     - Otherwise → COS 99             │
└──────────────────────────────────────┘
       ↓
   COS Code Assigned
```

## Key Features

### Override Logic
NJ2BE067 checks 3 specific conditions BEFORE calling COSMATRX:
- GSHP-related claims get COS 94 immediately
- Managed care claims get COS 37 immediately
- Lab-formatted procedure codes (outside outpatient) get COS 60 immediately

### COSMATRX Integration
NJ2BE067 calls ALL 109 COSMATRX rules via matrix traversal, but:
- Adds conditional exclusions for procedure-based rules
- Handles Medicare Part A (14/XX) and Part B (15/XX) crossovers
- Substitutes actual Medicare claim types for rule evaluation

### Conditional Exclusions
Procedure-based rules (PROCEDURE-CODE, PROCEDURE-AND-MODS, PROCEDURE-MOD-ONLY) are excluded when:
- Claim Type is 01 (Inpatient Hospital)
- Claim Type is 06 (Home Health)
- Medicare Part A Inpatient Hospital Crossover (14/01)
- Outpatient Lab Procedure flag is set

### Medicare Crossovers
Medicare crossover claims have their claim type substituted:
- **Part A (Claim Type 14)**: TT-A-MCARE-CLM-TYPE → 01, 02, 03
- **Part B (Claim Type 15)**: TT-B-MCARE-CLM-TYPE → 04, 05, 07-10, 16-19, 21-23

Example: A claim with Claim Type 15 and TT-B-MCARE-CLM-TYPE = 18 is evaluated as Claim Type 18 (Independent Clinic) for COSMATRX rules.

## Troubleshooting

### Script 1 fails
- Check that `cobol/NJ2BE067.cbl` exists
- Verify file encoding (should handle UTF-8 or ASCII)

### Script 2 fails
- Run Script 1 first to generate `NJ2BE067-rules-extracted.md`
- Check that `copybook/COSMATRX-integrated-report.md` exists

### LLM generates incomplete report
- Ensure you copied the entire `MERGE-PROMPT.txt` file
- Try using Claude Sonnet 4.5 or GPT-4 for best results
- If output is truncated, ask the LLM to continue from where it stopped

## Notes

- The consolidated report should have ~114 rules total (3 override + 109 COSMATRX + 2 fallback)
- Each rule should have clear natural language conditions
- Medicare crossover variations should be documented inline with the rules
- Multi-rule COS codes (3+ rules) should be documented individually, not summarized
- All procedure codes should be listed explicitly, never generalized
